About PercentURL

A free, private URL encoder and decoder that runs entirely in your browser.

← Back to the URL Encoder

PercentURL turns any string or full URL into percent-encoded form (and decodes it back) so it can travel safely inside links, query strings, and APIs. Everything is computed on your device — there is no server, no account, and nothing you type is ever sent anywhere.

What it does

URL encoding replaces unsafe characters (spaces, &, =, ?, non-ASCII text, etc.) with a %XX escape so the data keeps its meaning when placed in a URL. Decoding reverses it. This is the same encoding used by web browsers and servers everywhere.

Four controls

  • Character set — UTF-8 encodes any language correctly; ASCII keeps bytes 0–127 and escapes the rest (astral characters use %uXXXX for a safe round-trip).
  • Space as — emit spaces as %20 (strict) or + (form-style).
  • Encoding mode — RFC 3986 keeps only unreserved characters; encodeURIComponent keeps the wider set browsers use.
  • Newlines — encode the whole input as one block, or encode each line separately.

Private by design

  • No login, no sign-up, no limits on use.
  • No backend, no database, no analytics that identify you.
  • Your text never leaves your browser. Close the tab and it is gone.
