Convert URL Online: Encode or Decode a Complete URL

Paste a complete URL, then convert it without encoding the ://, slashes, question mark, or hash as ordinary text. The tool converts path, query, and fragment data separately so the URL keeps its structure.

What complete-URL conversion changes
InputEncoded resultBoundary kept
https://example.com/a pathhttps://example.com/a%20pathScheme, host, and path slash remain delimiters.
https://example.com/?q=a bhttps://example.com/?q=a%20bQuestion mark remains the query boundary.
https://example.com/#a bhttps://example.com/#a%20bHash remains the fragment boundary.
Why not encode the whole string?
Encoding the complete string as one component turns delimiters into data and changes the URL's meaning. This page treats the URL structure as syntax, then encodes the component text inside each part. Decoding reverses those component operations without inventing a new host or path boundary.
