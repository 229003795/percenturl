Common failure
Do not concatenate raw JSON after ?. An inner & becomes an outer parameter. Build the URL with a URL API, decode the parameter once, then parse JSON. Percent-encoding is transport formatting, not encryption.
FAQ
Should I encode JSON twice?
No. Encode the JSON once as the parameter value. A second pass changes literal percent signs.
Can JSON contain arrays?
Yes. The serialized JSON keeps array order; the query parser only sees one encoded value.
