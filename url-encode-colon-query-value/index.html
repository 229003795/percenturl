Encode a Colon in a URL Query Value

A colon in a query value is data; it is not the URL scheme separator once it is after the question mark. Encode it as %3A when the receiver must preserve it literally.

Context changes the meaning

Common failure
Do not encode the whole outer URL when only the query value is data. Encode the component, then let the outer URL keep its own ? and & structure.
FAQ
Should every colon be encoded?
No. Preserve syntax delimiters in the URL structure and encode colons that belong to a value.
Does percent-encoding change the decoded value?
After correct decoding, the value is still the same colon character; encoding only changes its wire representation.
