Encode an Equals Sign in a URL Query Value

The first equals sign separates a query key from its value; later equals signs can be data. Encode an equals sign as %3D when it belongs inside the value.

Separator or data
Wire formDecoded valueWhat can go wrong
token=a=bOften a=b after the first splitSome parsers split every equals sign.
token=a%3DbOne value: a=bThe inner equals is explicit data.
token=a%3Db%3DcOne value: a=b=cAll inner separators survive decoding.

Common failure
Do not split a raw query on every equals sign. Split the pair at the first separator, then percent-decode the value.
FAQ
Can an unencoded equals sign be data?
Some parsers preserve later equals signs, but that is a parser behavior. Encoding the data makes the intent explicit.
Does encoding change the value?
After correct decoding, the value is still the same equals character; only its wire form changes.
