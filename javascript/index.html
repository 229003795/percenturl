② Plain English: how these functions actually differ

  • Percent-encoding (URL encoding): rewrites the characters a URL cannot carry directly as % plus two hex digits. Spaces, &, =, ?# and every non-ASCII character get encoded.
  • encodeURIComponent(str): encodes everything except A-Z a-z 0-9 - _ . ! ~ * ' ( ). Use it to encode one value or one parameter — for example the value of a query parameter.
  • encodeURI(str): encodes only the characters that are genuinely illegal and keeps the URL structural characters :/?#@&=+$,;. Use it on a whole URL that is already correctly structured.
  • decodeURIComponent / decodeURI: turns %XX back into the original character. Use the decoder that matches the encoder you used.
  • Pitfall 1 — do not encode twice: encoding an already-encoded string turns % into %25 and makes the mess worse. Check first, then encode.
  • Pitfall 2 — + is not a space: encodeURIComponent(' ') returns %20, not +. + only means a space inside an application/x-www-form-urlencoded form submission.
  • Pitfall 3 — a whole URL must be encoded part by part: running encodeURIComponent over an entire URL also encodes :// ? & and breaks it. Encode the scheme, the host, each path segment, each parameter name and each parameter value separately (see the code below).

③ Code examples (hit Copy and paste them in)

1) Basic encoding: one parameter value
// encode a value so it can be used as a query parameter
const q = encodeURIComponent('café & tea');
// → "caf%C3%A9%20%26%20tea"
const url = 'https://example.com/search?q=' + q;
2) Building a query string safely
function buildQuery(params) {
  return Object.keys(params)
    .map(k => encodeURIComponent(k) + '=' + encodeURIComponent(params[k]))
    .join('&');
}
const qs = buildQuery({ q: 'café', page: 2 });
// → "q=caf%C3%A9&page=2"
3) Reading and decoding a parameter from the address bar (URLSearchParams)
// in a browser: decoded for you automatically
const params = new URLSearchParams(window.location.search);
const q = params.get('q');   // already the decoded original text

// decoding an encoded string by hand
const raw = 'caf%C3%A9';
const text = decodeURIComponent(raw);  // "café"
4) Encoding every part of a whole URL (the correct way)
function encodeUrl(url) {
  const u = new URL(url);
  u.pathname = u.pathname.split('/').map(encodeURIComponent).join('/');
  u.search = '?' + new URLSearchParams(
    [...new URLSearchParams(u.search)].map(
      ([k, v]) => [encodeURIComponent(k), encodeURIComponent(v)]
    )
  ).toString();
  return u.toString();
}
encodeUrl('https://example.com/café?q=café');
5) Preventing double-encoding
function safeEncode(str) {
  // if it already contains %XX, decode first so that we only encode once
  const decoded = /%[0-9A-Fa-f]{2}/.test(str) ? decodeURIComponent(str) : str;
  return encodeURIComponent(decoded);
}
