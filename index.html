Which settings should I use?

Plain English: percent-encoding (also called URL encoding) rewrites the characters a URL cannot carry directly as a percent sign plus two hex digits. A space becomes %20; an accented letter becomes a run of %XX groups.
· Component mode: encode / decode one piece of text, such as a single parameter value.
· Full URL mode: splits the URL into scheme / host / path / query / fragment and encodes each part on its own, keeping the structural characters (:// / ? & = #) intact.
· With batch on, every line is treated as its own item, and a bad line is reported on its own.
