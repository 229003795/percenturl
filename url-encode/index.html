What does a URL encoder do?
A URL encoder turns data such as spaces, ampersands, and plus signs into percent-encoded bytes. Use component mode for one value; use complete-URL mode when the URL delimiters are structure.
What is percent encoding?
Percent encoding writes a byte as % followed by two hexadecimal digits. A space becomes %20 and a literal plus sign becomes %2B; plus-as-space is a form-urlencoded rule.
How do I URL encode text?
Paste text above, keep Component value selected, and run the tool.
Should I encode a whole URL?
Not with component encoding: it would escape structural characters such as ://, ?, and &. Select Complete URL to preserve separators while encoding data.
What is the difference between URL encode and URL encode/decode?
This page encodes input. To decode an already encoded string, use URL Decode Online.
Component encoding is not complete-URL encoding
encodeURIComponent() treats the input as data and escapes delimiters such as ? and &. Complete-URL mode keeps the scheme, host, path slashes, query separator, and fragment marker as URL structure, then encodes the data inside those parts. Pick the mode that matches what the input means.
