Encode a Cookie Value for a URL Safely

A cookie value and a URL query value are different grammars: encode the value for the destination context instead of copying a URL encoder result into a Set-Cookie header. This tool shows the URL component result beside a conservative cookie-value check.

Do not confuse transport layers
Encoding a cookie value does not make it secret and does not validate a session. Do not put credentials in a URL; for query parameters, use the query parameter parser. For ordinary component encoding, use the URL Encode tool.
FAQ
Can I decode a cookie with decodeURIComponent?
Only if the producer used URL component encoding. Cookie libraries may apply a different decoding policy, so test the actual framework.
Does encoding fix security?
No. It prevents delimiter collisions; authentication, signing, expiry, and transport security remain separate controls.
