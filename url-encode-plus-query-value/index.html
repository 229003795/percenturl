Encode a Plus Sign in a URL Query Value

A literal plus sign is data, while form-style decoding often treats an unescaped plus as a space. Encode literal + as %2B; use %20 when the intended value is a space.

Common failure
Do not replace every plus with a space before deciding which parser contract applies. Check whether the input is a URL component or application/x-www-form-urlencoded data.
FAQ
Should a literal plus be encoded?
Yes. Use %2B when the receiver must get a plus character rather than a form-style space.
Is plus always a space?
No. Its meaning depends on the parser. A URL component and a form body can apply different rules to the same bytes.
