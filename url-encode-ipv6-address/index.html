Encode an IPv6 URL Without Breaking Brackets

Keep the square brackets around an IPv6 host structural; encode only the path or query value that is data. Encoding the whole host string turns the address into a different value and can make the URL parser reject it.

Three boundaries to compare
PartKeep or encodeObserved rule
[2001:db8::1]Keep bracketsThey mark an IPv6 host inside a URL authority.
:8443Keep colonThe port separator is structural after the closing bracket.
q=a&tag=c+dEncode valuesQuery ampersand separates parameters; plus may be data or a form-space convention.

Common failure
Do not run encodeURIComponent("[2001:db8::1]") when you mean a host. That creates data text for another context. Encode a query value such as c+d separately, then let the URL builder keep brackets and delimiters structural.
FAQ
Should an IPv6 address in a query be bracketed?
If it is a query value, it is data and may be encoded normally. Brackets are required for an IPv6 literal in the host position because the address itself contains colons.
Does encoding protect an IPv6 URL?
No. Encoding only prevents delimiter collisions; validation, authorization, and network policy remain separate.
