Encode Semicolon Matrix Parameters in a URL Path

A semicolon in a path can be a matrix-parameter delimiter, while a semicolon inside a value is data. Decide which role it has before encoding; encoding the whole path blindly can erase the boundary your router expects.

Three delimiters, three jobs
LocationExampleObserved boundary
Path matrix parameters/items;color=red;size=largeSemicolons may separate parameters inside a path segment.
Query separator?color=red&size=largeAmpersand separates query pairs, not path segments.
Value data?note=a%3BbAn encoded semicolon stays inside the value.

Common failure
Do not use query encoding rules to rewrite an entire path segment. Encode a value such as red;blue as red%3Bblue when it is data, but keep a router's structural semicolons only when that router documents matrix parameters.
FAQ
Are matrix parameters universal?
No. They are a path convention, not a requirement of every web framework. Test the actual router before relying on them.
Should I encode every semicolon?
Only semicolons that belong to data. Structural delimiters and data values must be separated deliberately.
