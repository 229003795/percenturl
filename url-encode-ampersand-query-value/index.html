Encode an Ampersand in a URL Query Value

An ampersand inside a query value is data; an unencoded ampersand separates query pairs. Encode it as %26 when the value must stay in one parameter.

Common failure
Do not paste raw user text into a query string and then split on ampersands afterward. Encode the component before joining it to the outer URL.
FAQ
Why does the browser show plus signs?
URLSearchParams serializes spaces with the form-style plus convention; the ampersand itself remains %26. This is distinct from encodeURIComponent, which uses %20 for spaces.
Can I use repeated keys for a list?
Yes, but use a list-aware parser such as getAll() so values are not silently discarded.
