URL Encode and Decode

Encode text for one URL value, preserve a complete link, or decode percent escapes back to readable text.

Choose what you are encoding

“URL encode” can mean different jobs. Pick the scope before converting: a value is data inside a URL; a full URL also contains characters that act as separators.

Your inputUseWhy

A complete URL whose structure should remain readableFull-URL encoding (encodeURI style), or encode its data parts separatelyKeeps delimiters such as ://, /, ?, and & in place.

Encode a query value without breaking the URL

Suppose a search value is red & blue=green. The ampersand and equals sign are part of the value, not separators between query parameters. Encode the value first, then place it after q=:

Value:         red & blue=green
Encoded value: red%20%26%20blue%3Dgreen
Complete URL:  https://example.com/search?q=red%20%26%20blue%3Dgreen

If you insert the raw text as ?q=red & blue=green, a query-string parser can interpret the ampersand as the start of another parameter. Encoding the value preserves the intended boundary.

Why a space can be %20 or +

%20 is the percent-encoded UTF-8 byte for a space. A plus sign is a space marker in the form-encoding convention, but in an ordinary URL a literal + can mean plus. To represent an actual plus in form data, encode it as %2B.

Original valuePercent styleForm style
a ba%20ba+b
a+ba%2Bba%2Bb

When decoding, treat + as a space only when the data uses form encoding. Otherwise leave it as a plus sign.

Decode percent-encoded text

Read each %XX as one hexadecimal byte, then decode the byte sequence as UTF-8. A non-ASCII character may need several bytes: é is UTF-8 C3 A9, so it appears as %C3%A9.

Encoded: %E6%97%A5%E6%9C%AC%E8%AA%9E%20URL
Decoded: 日本語 URL

Use the decoder on the encoded portion when possible. Decoding a complete link can make reserved characters visible again; that is useful for inspection, but may change how the link is parsed if copied into another URL without re-encoding its values.

Common errors and what to do

A URL becomes unreadable after encoding

You likely encoded the entire address as one component. Its colon, slashes, question mark, and ampersands became data too. Encode each path segment or query name/value separately, then join them with the URL separators.

A value is split at an ampersand

Encode the ampersand inside the value as %26. Keep the real ampersands that separate query parameters.

The output contains %2520

This usually means %20 was encoded again: the percent sign became %25. Use the original text, or decode one layer before encoding once for the intended context.

Decoding reports an invalid percent escape

A percent sign must be followed by two hexadecimal digits, such as %20. Check for a truncated escape like %2 or a stray %. Do not silently replace malformed data if exact recovery matters.

Quick checks before you copy

  • Encode only the data portion, not URL structure.
  • Choose %20 or form-style + to match the receiving system.
  • Encode a literal plus as %2B when the receiver treats plus as a space.
  • For non-ASCII text, use UTF-8 percent encoding.
  • Decode once, then inspect whether another encoded layer is genuinely expected.
